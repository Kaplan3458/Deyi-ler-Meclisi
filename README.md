# Deyişler Meclisi

Doğru metinleri ve mahlaslarıyla deyişleri kolayca bulmak ve birlikte okumak için hazırlanmış, GitHub Pages üzerinde ücretsiz çalışabilen statik site.

## Deyiş ekleme

1. Ana dizindeki `deyisler.js` dosyasını açın.
2. Var olan örnek kayıtlardan birini kopyalayın.
3. `id`, `baslik`, `mahlas`, `tur`, `konular`, `metin` ve gerekiyorsa `not` alanlarını değiştirin.
4. Her kaydın `id` değeri benzersiz ve küçük harflerle yazılmış olmalıdır.
5. Ekran görüntüsünden aktarılan kayıtlardaki doğrulama notunu, metni asıl kaynaktan kontrol ettikten sonra kaldırın.

Site, kayıtları Türk alfabesine göre otomatik sıralar. Arama; başlık, mahlas, tür, konu ve şiirin tam metni içinde çalışır.

## GitHub Pages'te yayımlama

1. GitHub'da yeni ve herkese açık bir depo oluşturun.
2. Bu paketin içindeki bütün dosyaları depoya yükleyin.
3. Deponun **Settings → Pages** bölümüne girin.
4. **Source** alanında **Deploy from a branch** seçin.
5. Dal olarak **main**, klasör olarak **/(root)** seçip kaydedin.
6. GitHub Pages bağlantısının oluşması için birkaç dakika bekleyin.

## Önemli içerik kuralı

Mahlası veya metni doğrulanmamış bir kaydı doğrudan yayımlamayın. İnternet araması yalnızca aday metinleri bulmaya yarar; son doğrulama arşiv sorumlusu tarafından yapılmalıdır.
